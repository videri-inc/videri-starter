# Security

If you find a security issue in this repository or in the Videri platform
while building on it, do not open a public issue. Use GitHub's private
vulnerability reporting on this repository ("Report a vulnerability" under
the Security tab), or email security@videri.com.

Never include API keys, passwords, tokens, tenant codes or device identifiers
in an issue, a pull request or a recipe. If you committed one by accident,
revoke it first, then tell us.
